## Failures found (not fixed in week 1)

1. Grader too lenient: signature check is substring containment. INC-002 passed while leading with
   "PoolTimeout" (symptom); CacheMissStorm only appeared in a parenthesis. Fix: exact match on a short id.
2. error_signature returned as a sentence, not a stable id. Fix: tighter field description + short Literal/regex.
3. first_error_ts loses milliseconds (ts BAD on INC-002/004/005; OK ones had .000). Fix: model returns the
   line number, code reads the timestamp from that line.
4. Cost logger ignored Haiku's >100K-token price tier: under-reported 5x. Fixed with LONG_TIER in llm.py.
5. Run-to-run variance: same input gave 5 vs 3 citations. Grade against truth, not against a previous run.

## Lessons

- Schema guarantees shape, Pydantic guarantees bounds, only code guarantees truth.
- Anything code can compute exactly (timestamps, line numbers, cost) should not come from the model.
- Measure tokens, never estimate from characters.
- Streaming improves time-to-first-token only; same total latency and cost.
- Biggest cost lever: keep prompts under 100K tokens (prefilter / retrieve). That is week 2-3.
